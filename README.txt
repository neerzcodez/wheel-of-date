# A Little Question 💌

A cute single-page date-question website.

## Run it
Just double-click `index.html`, or open it in any browser.

## The "rigged" wheel
The wheel visually has an 80% NO section and a 20% YES section. The wheel itself does not rotate. Instead, the pointer rotates around its own center pivot and always returns to `0deg`, where YES is positioned.

So it looks like the pointer has spun, but the final answer is always YES → “It’s a date. 💗”
